Terrorist Incidents by Country, Western Europe (1970–2020)

Tableau · Global Terrorism Database · Open on Tableau Public ↗

Drag the Year slider to see one year at a time. If the map doesn't load, view it on Tableau Public.

Problem

Where in Western Europe did terrorist attacks happen, and how did that change over 50 years? A raw table of 17,328 incidents can't answer that at a glance. I wanted one interactive map where anyone can pick a year and see right away which countries were hit hardest.

Approach

I used the Global Terrorism Database file for Western Europe (GTD region 8): 17,328 incidents in 23 countries, 1970–2020.

  1. Loaded region_8.csv into Tableau and checked that the location fields were read as geographic data.
  2. Gave the country field a Country/Region role so Tableau could draw each country as a filled shape.
  3. Colored each country by the number of attacks. Each incident has one unique eventid, so a distinct count of it gives the attack total.
  4. Turned the year column into a discrete dimension and added it as a single-value slider, so the map shows one year at a time.
  5. Added a clean tooltip (country and attack count), renamed the legend to "Number of Attacks", and checked the totals against the raw data.
  6. Published the workbook to Tableau Public.

Challenges

  • 541 incidents were missing from the map. Records from 1970–1990 list the country as "West Germany (FRG)", a name Tableau can't place on a map. I wrote a calculated field that maps it to "Germany", so all German incidents (1,357 total) show as one shape. The trade-off: pre-1990 West German attacks appear inside today's German borders.
  • The calculated field threw "Can't compare integer and string values". The data also has a numeric country code column, and Tableau ignores case in field names, so [Country] pointed at the number column instead of the text one. Renaming the text field to Country Name and using [Country Name] fixed it.
  • The color showed a meaningless sum. Dropping eventid on Color added up the ID numbers. Switching the measure to Count (Distinct) made each incident count once.
  • The year acted like a number, not a filter. Tableau loaded the year as a continuous measure. Converting it to a discrete dimension made the year slider work.

Insights

  • Attacks were concentrated in a few countries. Across all 50 years, the UK had the most incidents (5,513), followed by Spain (3,255) and France (2,751). Together they make up about 66% of the region's 17,328 incidents.
  • The worst year was 1979, not recent decades. That year had 1,020 incidents, led by Spain (279), the UK (239) and France (212). This lines up with long-running separatist conflicts such as Northern Ireland and the Basque Country.
  • The pattern shifted over time. By 2015 the total was far lower, but the ranking had changed: the UK led with 114, and Germany moved to second with 68.
  • Data quirks matter. 5,304 incidents have no known group, and many have blank death or injury counts. Any follow-up analysis of groups or casualties has to deal with these gaps first.
